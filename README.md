# Hi, I'm Teja

**Software developer · Founder of [AudioZem](https://audiozem.com)**

I build web products and AI integrations, from the user interface and backend APIs to background processing and deployment. I recently completed my M.S. in Computer Science at Florida Atlantic University.

## What I'm working on

I'm building **AudioZem**, a product that turns text, PDFs, and images into natural-sounding audio. My work includes the Next.js/React frontend, Node.js/Express APIs, authentication, speech integrations, background jobs, and production support.

I enjoy solving the problems that appear after a product starts working: long documents, failed jobs, unusable output, and making the experience reliable for users.

## Featured work

### [AudioZem Engineering Showcase](https://github.com/dineshnagateja/audiozem-engineering-showcase)

A public overview of AudioZem's architecture, plus a standalone TypeScript example for splitting long text into byte-limited chunks without losing content.

- Runs locally without API keys or a database.
- Includes tests for multilingual text, emoji, and exact text reconstruction.
- Includes a runnable demo and automated GitHub checks.
- The sample is an educational implementation inspired by the product's workflow; the full production application is private.
